Premium AI writing assistant for WordPress and WooCommerce with provider management, product SEO automation, prompt library, history, queue, image generation, exports, caching, and logs.

== Description ==

AI SEO Content Studio adds a secure, modular AI workspace to WordPress. It supports OpenAI, Google Gemini, Anthropic Claude, DeepSeek, OpenRouter, Groq, Ollama local AI, and unlimited OpenAI-compatible custom providers.

WooCommerce product editors receive a full AI panel that detects product title, categories, tags, attributes, brand, price, SKU, custom fields, images, short description, and existing description. One click can generate a complete SEO product content package including long description, short description, title, meta, keywords, slug, benefits, features, specifications, FAQ, schema, image SEO, social captions, marketing copy, tags, naming ideas, links, related products, and SEO score.

== Installation ==

1. Upload the plugin folder to wp-content/plugins/ai-seo-content-studio or install the zip in WordPress.
2. Activate AI SEO Content Studio.
3. Open AI SEO Studio in the admin menu.
4. Add API keys for the AI providers you want to use.
5. Edit a WooCommerce product and use the AI panel.

== Security ==

The plugin uses WordPress REST nonces, capabilities, sanitized input, escaped output, encrypted API key storage, prepared database operations, and WordPress HTTP APIs.
