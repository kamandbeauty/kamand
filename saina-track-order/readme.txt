پیگیری سفارشات ووکامرس با نوار پیشرفت، کد رهگیری پستی، پیامک، ایمیل و فرم جستجوی مشتری.

== Description ==

ساینا ترک‌اوردر امکاناتی مشابه افزونه نوین ترک‌اوردر را با نام و رابط اختصاصی ساینا فراهم می‌کند:

* فرم پیگیری با شماره سفارش، موبایل، ایمیل یا حالت ترکیبی
* نوار پیشرفت ۵ مرحله‌ای قابل‌سفارشی (انجام، بررسی، بسته‌بندی، ارسال، تحویل)
* متاباکس ثبت کد رهگیری، حامل و تاریخ شمسی ارسال/تحویل
* درج گروهی و درون‌ریزی CSV/Excel
* وضعیت‌های بسته‌بندی و تحویل‌شده
* شورتکد پیامک: {tracking_code} {carrier} {ship_date} {delivery_date}
* درج جزئیات ارسال در ایمیل ووکامرس
* دکمه پیگیری پست ایران، چاپار و تیپاکس
* کپچای عددی و فیلدهای reCAPTCHA
* سازگاری HPOS و همگام‌سازی کد تاپین/مسیر
* تأیید دریافت توسط مشتری و تبدیل خودکار تکمیل‌شده به تحویل‌شده

شورتکد: `[saina_track_order]`

== Installation ==

1. پوشه `saina-track-order` را در `wp-content/plugins` کپی کنید.
2. افزونه را فعال کنید. برگه «پیگیری سفارش» به‌صورت خودکار ساخته می‌شود.
3. از منوی «ساینا ترک‌اوردر» تنظیمات، درج گروهی و درون‌ریزی را انجام دهید.
