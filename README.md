# راهنمای سایز ووکامرس — از استودیو جاوید

افزونهٔ **راهنمای سایز ووکامرس** جدول راهنمای سایز هر محصول را با ظاهری تمیز و واکنش‌گرا،
دقیقاً **زیر دکمهٔ «افزودن به سبد خرید»** در صفحهٔ محصول ووکامرس نشان می‌دهد.

> نسخهٔ فعلی: **۱.۰.۰** · نیازمند وردپرس ۵.۹+، ووکامرس ۶.۰+ و PHP ۷.۴+

---

## چرا این افزونه؟

مشتری باید پیش از کلیک روی دکمهٔ خرید بداند کدام سایز برای او درست است. این افزونه همان
جدول را در همان نقطهٔ تصمیم‌گیری قرار می‌دهد؛ نه در یک تب پنهان و نه در یک پاپ‌آپ که
باید بازش کرد.

| قابلیت | توضیح |
| --- | --- |
| جدول زیر دکمهٔ خرید | به‌صورت پیش‌فرض روی هوک `woocommerce_after_add_to_cart_form` |
| چند راهنما به‌صورت تب | یک محصول می‌تواند همزمان راهنمای پوشاک و راهنمای کفش داشته باشد |
| تبدیل سانتی‌متر/اینچ | اعداد ستون‌های «عدد اندازه‌گیری» واقعاً ضرب/تقسیم در ۲٫۵۴ می‌شوند |
| برجسته‌سازی سایز انتخاب‌شده | در محصولات متغیر، با انتخاب سایز، ردیف همان سایز برجسته می‌شود |
| پنجرهٔ بزرگ‌نمایی و چاپ | برای موبایل و برای مشتریانی که می‌خواهند جدول را چاپ کنند |
| سه سطح تعیین راهنما | راهنمای اختصاصی محصول ← راهنمای دسته‌بندی ← راهنمای پیش‌فرض فروشگاه |
| شورت‌کد | `[ksg_size_guide]` برای نمایش در هر جای محتوا |
| بدون jQuery | فقط JavaScript خام؛ دارایی‌ها فقط در صفحهٔ محصول بارگذاری می‌شوند |

## نصب

1. پوشهٔ `kamand-size-guide` را در `wp-content/plugins/` بگذارید (یا همان پوشه را زیپ کرده و از پیشخوان نصب کنید).
2. افزونه را فعال کنید.
3. از منوی **راهنمای سایز** یک راهنما بسازید: ستون‌ها را تعریف کنید، ردیف‌ها را پر کنید و در صورت نیاز نکته و تصویر راهنما اضافه کنید.
   می‌توانید جدول را مستقیماً از اکسل یا گوگل‌شیت کپی و در بخش «ساخت جدول از متن» جای‌گذاری کنید.
4. در **ووکامرس › راهنمای سایز** رنگ اصلی، محل نمایش و راهنمای پیش‌فرض فروشگاه را تنظیم کنید.
5. در صفحهٔ ویرایش هر محصول، متاباکس «راهنمای سایز (استودیو جاوید)» سه حالت دارد:
   - **ارث‌بری**: از دسته‌بندی محصول یا پیش‌فرض فروشگاه استفاده می‌کند
   - **راهنمای اختصاصی**: یک یا چند راهنمای آماده، یا جدول اختصاصی همان محصول
   - **بدون راهنما**: چیزی نمایش داده نمی‌شود

برای تعیین راهنمای پیش‌فرض یک دسته، به **محصولات › دسته‌ها** بروید و در فرم افزودن/ویرایش
دسته، فیلد «راهنمای سایز پیش‌فرض» را پر کنید. زیردسته‌ها همان راهنما را به ارث می‌برند.

## ساختار داده

هر راهنما یک نوشته از نوع `ksg_size_guide` است و جدولش در متای `_ksg_table` ذخیره می‌شود:

```php
array(
    'unit'    => 'cm',                 // cm | inch
    'columns' => array(                // حداکثر ۱۲ ستون
        array( 'id' => 'c_size', 'label' => 'سایز',     'kind' => 'size' ),
        array( 'id' => 'c_bust', 'label' => 'دور سینه', 'kind' => 'measure' ),
        array( 'id' => 'c_note', 'label' => 'معادل',    'kind' => 'note' ),
    ),
    'rows'    => array(                // حداکثر ۸۰ ردیف
        array( 'id' => 'r_m', 'values' => array( 'c_size' => 'M', 'c_bust' => '92', 'c_note' => '۳۸' ) ),
    ),
    'tips'    => array( '...' ),       // نکته‌های اندازه‌گیری
    'note'    => '...',                // توضیح زیر جدول
    'image'   => 0,                    // شناسهٔ تصویر راهنما
)
```

نوع ستون مهم است:

- `size` — برچسب سایز؛ برای برجسته‌سازی خودکار در محصولات متغیر استفاده می‌شود
- `measure` — عدد اندازه‌گیری؛ با کلید واحد تبدیل می‌شود
- `note` — متن آزاد؛ بدون تبدیل

متاهای محصول: `_ksg_mode` (inherit/custom/none)، `_ksg_guide_ids` و `_ksg_inline_table`.
متای دسته‌بندی `product_cat`: `ksg_guide_id`.

## نقطه‌های توسعه

| هوک | نوع | کاربرد |
| --- | --- | --- |
| `ksg_product_guides` | فیلتر | تغییر یا افزودن راهنمای یک محصول پیش از نمایش |

```php
add_filter(
    'ksg_product_guides',
    function ( $guides, $product_id ) {
        if ( has_term( 'outlet', 'product_cat', $product_id ) ) {
            return array(); // برای محصولات حراج، جدول نشان نده
        }

        return $guides;
    },
    10,
    2
);
```

محل نمایش از تنظیمات انتخاب می‌شود و به این هوک‌ها نگاشت می‌شود:

| انتخاب | هوک | اولویت |
| --- | --- | --- |
| زیر دکمهٔ خرید (پیش‌فرض) | `woocommerce_after_add_to_cart_form` | ۱۰ |
| بالای تب‌های توضیحات | `woocommerce_after_single_product_summary` | ۸ |
| زیر تب‌های توضیحات | `woocommerce_after_single_product_summary` | ۲۵ |

ظاهر جدول با متغیرهای CSS قابل بازنویسی است:

```css
.ksg {
    --ksg-accent: #e0447c;
    --ksg-accent-soft: rgba(224, 68, 124, 0.09);
    --ksg-radius: 18px;
}
```

## بررسی کیفیت

این مخزن برای بررسی، به محیط شبیه‌ساز توابع وردپرس در `tests/bootstrap.php` تکیه می‌کند؛
بنابراین بدون نصب وردپرس هم می‌توان مسیرهای اصلی افزونه را اجرا کرد.

```bash
# بررسی نحو همهٔ فایل‌های PHP
find kamand-size-guide tests tools -name '*.php' -exec php -l {} \;

# اجرای آزمون‌های سمت سرور (۸۷ بررسی)
php tests/run-tests.php

# اجرای آزمون‌های رفتار اسکریپت فروشگاه در jsdom (۲۷ بررسی)
cd tests/js && npm install && node run-tests.mjs
```

آزمون‌های PHP این مسیرهای واقعی افزونه را اجرا می‌کنند: پاک‌سازی دادهٔ جدول، تشخیص راهنمای
محصول از سه سطح، ساخت HTML بخش زیر دکمهٔ خرید، شورت‌کد، متاباکس محصول و صفحهٔ تنظیمات.
آزمون‌های jsdom هم فایل واقعی `assets/js/frontend.js` را اجرا می‌کنند و تبدیل
سانتی‌متر/اینچ، برجسته‌سازی سایز انتخاب‌شده، تب‌ها و پنجرهٔ بزرگ‌نمایی را می‌سنجند.

برای دیدن ظاهر جدول بدون وردپرس:

```bash
php tools/generate-demo.php demo
python3 -m http.server 3000 --directory demo
```

`demo/` خروجی ساخت است و در Git ثبت نمی‌شود.

## امنیت و داده

- همهٔ ورودی‌های فرم با `sanitize_text_field`، `sanitize_textarea_field`، `absint` و `sanitize_hex_color` پاک‌سازی می‌شوند.
- همهٔ خروجی‌ها با `esc_html`، `esc_attr` و `wp_json_encode` فرار می‌کنند.
- ذخیرهٔ متاباکس‌ها با nonce و `current_user_can` محافظت می‌شود.
- حذف افزونه از پیشخوان، همهٔ راهنماها، متاهای محصول، متای دسته‌ها و تنظیمات را پاک می‌کند (`uninstall.php`).
