## این چیست؟

روزی یک To-Do روزانه است که برای فارسی‌زبان‌ها ساخته شده — نه یک اپ انگلیسی که فارسی‌اش کرده باشند.
تقویمش **واقعاً جلالی** است، اعدادش فارسی‌اند، چیدمانش RTL است و هیچ داده‌ای از دستگاه شما خارج نمی‌شود.

هدف طراحی: کاربر بتواند در چند ثانیه کار جدید بسازد، برنامهٔ روزش را ببیند و از انجام دادن کارها حس خوبی بگیرد.

| | |
|---|---|
| **زبان‌ها** | فارسی (شمسی، اعداد فارسی، RTL) · English (Gregorian, LTR) |
| **حداقل اندروید** | 7.0 (API 24) — هدف API 35 |
| **حجم وابستگی‌ها** | بدون DI framework، بدون کتابخانه‌ی شبکه |
| **مجوزها** | فقط اعلان، هشدار دقیق و ریبوت |

## شروع سریع

```bash
cd roozi
./gradlew :app:assembleDebug        # بیلد دیباگ
./gradlew :app:testDebugUnitTest    # تست‌های واحد
./gradlew :app:assembleRelease      # APK ریلیز
./gradlew :app:bundleRelease        # AAB برای فروشگاه
```

نیازمندی: **JDK 17** و **Android SDK 35** (AGP 8.7.3 · Kotlin 2.0.21 · Compose BOM 2024.12).

### دیدن طراحی بدون بیلد

```bash
cd roozi/preview && python3 -m http.server 8080
```

سپس `http://localhost:8080` — می‌توانید بین فارسی/انگلیسی و روشن/تیره سوییچ کنید، کارها را تیک بزنید و در تقویم شمسی جابه‌جا شوید.

## قابلیت‌ها

**Daily Planner** — صفحهٔ امروز یک برنامهٔ روزانه است، نه فقط یک لیست: سلام هوشمند، حلقهٔ پیشرفت انیمیت‌شده، نوار افزودن سریع (با ورود صوتی)، سپس «برنامه امروز» (زمان‌دار) ← «هر وقت امروز» ← «بدون تاریخ» ← «انجام‌شده‌ها». جشن کوتاه وقتی همهٔ کارهای روز تمام شد.

**تاریخ اختیاری** — «خرید نان» فقط عنوان می‌خواهد. کار می‌تواند بدون تاریخ، فقط با تاریخ، یا با تاریخ و ساعت باشد؛ هیچ‌کدام اجباری نیست و کار بدون ساعت هرگز ساعت جعلی نمی‌گیرد.

**تکرار** — هر روز، هر هفته، روزهای خاص (مثلاً ورزش شنبه/دوشنبه/چهارشنبه)، هر ماه (اجاره روز اول هر ماه — بر مبنای ماه **شمسی**) یا هر N روز.

**ویجت‌ها** — ویجت «امروز» با تیک زدن مستقیم روی صفحهٔ اصلی، و ویجت کوچک «افزودن کار». هر دو با دیتابیس اپ سینک‌اند.

**پوسته‌های رنگی** — ۶ پوسته 🌈 🌿 🌊 🌸 🌅 🌙 که کل هویت رنگی را عوض می‌کنند و همگی Dark Mode دارند.

**تقویم** — تقویم شمسی واقعی با اندیکاتور تعداد کار هر روز، سوایپ بین ماه‌ها، دکمهٔ «امروز» و نمایش کارهای روز انتخاب‌شده.

**افزودن کار** — مسیر سریع: `+` ← عنوان ← ذخیره. بقیهٔ فیلدها (توضیحات، دسته‌بندی، تاریخ، ساعت، اولویت، یادآوری) پشت یک دکمهٔ «گزینه‌های بیشتر» پنهان‌اند.

**تعامل** — سوایپ راست = انجام شد، سوایپ چپ = حذف (با Undo)، نگه‌داشتن = منوی کامل کار (انتقال به امروز/فردا/روز دلخواه، یادآوری، ویرایش)، و Drag & Drop برای مرتب‌سازی.

**پروفایل** — آمار (انجام‌شده، انجام‌نشده، درصد موفقیت)، نمودار هفتگی، روزهای متوالی 🔥، مدیریت دسته‌بندی‌ها، تم، زبان، و پشتیبان‌گیری.

**یادآوری** — حتی وقتی اپ بسته است کار می‌کند، بعد از ریبوت دوباره تنظیم می‌شود، و دکمهٔ «انجام شد» مستقیم روی نوتیفیکیشن دارد.

## تصمیم‌های فنی قابل توجه

**تقویم شمسی واقعی است، نه ظاهری.** پیاده‌سازی الگوریتم چرخهٔ ۳۳ سالهٔ (Borkowski/خیام) در `core/date/JalaliDate.kt`. تبدیل‌ها خالص و بدون side-effect‌اند تا تست‌پذیر باشند. همین تقویم هم در تب «تقویم» و هم در انتخاب تاریخِ افزودن کار استفاده می‌شود — کاربر فارسی هیچ‌جا تاریخ میلادی نمی‌بیند.

**یادآوری بدون مجوز حساس.** به‌جای `SCHEDULE_EXACT_ALARM` (که فروشگاه‌ها برای اپ To-Do رد می‌کنند) از `setAndAllowWhileIdle` استفاده شده: مقاوم در برابر Doze و بدون دردسر انتشار. مجوز اعلان هم فقط موقع ساخت اولین کار درخواست می‌شود، نه در اولین اجرا.

**ذخیره‌سازی مستقل از منطقهٔ زمانی.** تاریخ به‌صورت `epochDay` و ساعت به‌صورت دقیقه از نیمه‌شب ذخیره می‌شود؛ شمسی/میلادی صرفاً لایهٔ نمایش است. پس سفر بین تایم‌زون‌ها تاریخ کارها را جابه‌جا نمی‌کند.

**بدون متن هاردکد.** تمام رشته‌ها در منابع‌اند و یک اسکریپت بررسی، وجود متن فارسی داخل کاتلین را به‌عنوان خطا گزارش می‌کند.

## تست و اعتبارسنجی

منطق تقویم و streak واقعاً **اجرا** شده‌اند (نه فقط نوشته):

| بررسی | نتیجه |
|---|---|
| رفت‌وبرگشت میلادی↔شمسی، ۱۹۰۰ تا ۲۱۵۰ | ✅ ۹۱٬۳۱۱ روز بدون خطا |
| سال‌های کبیسه ۱۳۹۵–۱۴۲۰ | ✅ ۱۳۹۵، ۱۳۹۹، ۱۴۰۳، ۱۴۰۸، ۱۴۱۲، ۱۴۱۶، ۱۴۲۰ |
| پیوستگی آخر اسفند ← ۱ فروردین (۱۳۰۰–۱۵۰۰) | ✅ |
| طول اسفند کبیسه (۳۰) و عادی (۲۹) | ✅ |
| منطق روزهای متوالی (streak) | ✅ ۶ سناریو |
| تکرار: هفتگی همیشه روی روزهای درست و رو به جلو | ✅ ۵۰ تکرار متوالی |
| تکرار ماهانه همیشه روی روز ۱ ماه شمسی | ✅ ۳۶ ماه |
| Drag & Drop: بدون گم/تکراری شدن آیتم | ✅ ۷ سناریو |
| سازگاری امضای توابع و فراخوانی‌ها | ✅ ۶۹ تعریف |
| کامپایل کل سورس کاتلین | ✅ بدون خطا |

```bash
./gradlew :app:testDebugUnitTest       # تست‌های واحد
python3 tools/verify_resources.py      # منابع، ترجمه‌ها، متن هاردکد، مجوزها
python3 tools/check_callsites.py       # سازگاری امضای توابع با محل فراخوانی
```

اسکریپت `verify_resources.py` این‌ها را چک می‌کند: صحت XML، تطابق کامل رشته‌های فارسی/انگلیسی و format specifierها، resolve شدن تمام `R.*`ها، نبود متن فارسی هاردکد، هشدار در صورت افزوده شدن مجوز `INTERNET`، و سالم بودن فونت‌ها و آیکون‌ها.

## انتشار

**تغییر نام و شناسه** — بدون دست‌زدن به سورس:

```bash
./gradlew :app:assembleRelease -PapplicationId=com.yourcompany.roozi -PappName="روزی"
```

**امضا** — یک `roozi/keystore.properties` بسازید (در `.gitignore` است):

```properties
storeFile=roozi.jks
storePassword=******
keyAlias=roozi
keyPassword=******
```

با وجود این فایل، `assembleRelease` خروجی امضاشده و آمادهٔ **کافه‌بازار / مایکت** می‌دهد.

**CI** — فایل `roozi/ci/roozi-android.yml` را در `.github/workflows/` قرار دهید تا تست، لینت، APK و AAB خودکار ساخته و آپلود شوند.

جزئیات کامل معماری، دیتابیس و بیلد در **[`roozi/README.md`](roozi/README.md)**.
