## این چیست؟

نسخهٔ موبایلِ بازی کلاسیک **حکم**؛ برگرفته از سنت ایرانیِ بازی با ورق،
با گرافیک رویه‌ای (procedural)، انیمیشن‌های نرم، صدای ساخته‌شده درون‌برنامه‌ای
و هوشی مصنوعی که طبق قوانین بازی می‌کند و تقلب نمی‌کند.

| | |
|---|---|
| **بازیکنان** | شما + هوش مصنوعیِ هم‌تیمی در برابر دو حریفِ هوش مصنوعی |
| **سطح‌بندی** | آسان · معمولی · سخت |
| **پلتفرم** | اندروید (APK) — Flutter + Flame |
| **داده** | هیچ داده‌ای از دستگاه خارج نمی‌شود |

## ساختار مخزن

```
hokm/           پروژهٔ کامل فلاتر «حکم با هوش مصنوعی»
├── lib/        موتور بازی، هوش مصنوعی، رابط کاربری، گرافیک و صدا
├── android/    پروژهٔ اندروید (Gradle + AGP 8)
├── test/       تست‌های موتور، هوش مصنوعی و ویجت
└── ci/         نسخهٔ مرجع ورک‌فلوی GitHub Actions
```

## بیلد و CI

- با هر پوش روی برنچ کاری، CI اجرا می‌شود: `flutter analyze` + همهٔ تست‌ها
  و سپس بیلد APK ریلیز؛ خروجی به‌عنوان artifact با نام `hokm-release-apk`
  آپلود می‌شود.
- نسخهٔ مرجع ورک‌فلو: [`hokm/ci/hokm-flutter.yml`](hokm/ci/hokm-flutter.yml)
  (راهنمای همگام‌سازی در [`hokm/ci/README.md`](hokm/ci/README.md)).
- مستندات کامل بازی: [`hokm/README.md`](hokm/README.md).
