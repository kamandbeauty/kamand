## قابلیت‌های کلیدی

**دوزبانه کامل** — فارسی (RTL، تقویم جلالی) و انگلیسی (LTR، میلادی) با سوییچ آنی بدون رفرش. تبدیل تاریخ با یک پیاده‌سازی سبک داخلی (بدون Composer و بدون کتابخانه خارجی).

**۱۴ جدول InnoDB** با `$wpdb->get_charset_collate()` و سیستم خودمراقبتی: در هر بار لود شورت‌کد یا فراخوانی REST، نبود جداول تشخیص داده و بی‌درنگ ساخته می‌شود.

**دو پروفایل کاملاً مجزا** — `gatherer` (شخصیت‌شناسی، کیف پول، گالری، تاریخچه) و `cafe_owner` (بهره‌وری، منو، تسویه، ثبت حضور)، هرکدام با نوار تب اختصاصی خودشان.

**موتور تطابق هوشمند** با دو مسیر: خودکار وقتی آخرین صندلی پر شود، و Cron اجباری چند ساعت قبل از رویداد. الگوریتم Greedy + Local Search میز N نفره می‌چیند و در حالت ثبت‌نام کم معیارها را نرم می‌کند — ولی قید بلاک‌لیست هرگز نقض نمی‌شود.

**پرداخت واقعی ووکامرس** — خالی‌کردن سبد، افزودن بلیت با قیمت لایو رویداد، انتقال به `wc_get_checkout_url()`. منوی کافه فقط نمایشی است؛ هیچ سفارشی از طریق افزونه انجام نمی‌شود.

**آماده WebView/APK** — حالت standalone با `?webview=1` (بدون هدر/فوتر قالب)، ناوبری SPA بدون رفرش، مدیریت دکمه Back با History API، و manifest + service worker تولیدشده توسط خود افزونه.

## تست‌های انجام‌شده

| بررسی | نتیجه |
|---|---|
| Syntax تمام ۲۲ فایل PHP و ۲ فایل JS | ✅ |
| پوشش مشخصات (۹۷ مورد از بخش‌های ۰ تا ۸) | ✅ ۹۷/۹۷ |
| صحت تقویم جلالی (موارد شناخته‌شده + رفت‌وبرگشت ۱۹۵۰–۲۱۰۰) | ✅ |
| سناریوهای موتور تطابق (توازن جنسیتی، بلاک‌لیست، ثبت‌نام کم، سرریز) | ✅ هیچ کاربری حذف نشد |
| ریسپانسیو در ۸ اندازه (۳۲۰px تا تبلت + لندسکیپ) | ✅ بدون سرریز افقی |
| پالت رنگی مطابق موکاپ (بدون بنفش/صورتی نئونی) | ✅ |
| امنیت: ABSPATH، prepare، escape، nonce، permission | ✅ ۴۷/۴۷ اندپوینت |

**یک باگ واقعی در حین تست پیدا و رفع شد:** الگوریتم جلالی به تقسیم truncating نیاز دارد نه `floor()` — با floor تمام تاریخ‌ها تا یک سال جابه‌جا می‌شدند (مثلاً ۲۰۲۴-۰۳-۲۰ به‌جای ۱۴۰۳/۱/۱ می‌شد ۱۴۰۲/۱۲/۲۹). همچنین ترکیب `strtotime` با `gmdate` حذف شد تا تاریخ‌ها با تایم‌زون سرور جابه‌جا نشوند.
