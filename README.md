# فاکتور روبی (Factor Ruby) - اپلیکیشن اندرویدی صدور فاکتور و مدیریت مالی

اپلیکیشن حرفه‌ای، سریع و کاملاً آفلاین برای صدور فاکتور، مدیریت مشتریان، کالاها، بدهی‌ها و گزارش‌های سود و زیان با نام **«فاکتور روبی»**؛ مناسب فروشگاه‌ها، کسب‌وکارهای کوچک، فریلنسرها و استفاده شخصی در ایران.

## 🌟 قابلیت‌ها و امکانات اپلیکیشن

### ۱. Onboarding چندمرحله‌ای دقیقاً مطابق اسکرین‌شات‌ها
- **مرحله ۱ (نام کاربر):** «سلام! من روبی هستم - همراه همیشگی تو توی مسیر صدور فاکتور و مدیریت کارهات. برای شروع اسمتو بهم بگو»
- **مرحله ۲ (انتخاب ارز):** ریال، تومان (پیش‌فرض)، دلار، یورو، دلار کانادا، لیر، افغانی همراه با پرچم کشورها
- **مرحله ۳ (انتخاب استان و شهر):** لیست کامل استان‌ها و شهرهای ایران با قابلیت جستجوی سریع
- **مرحله ۴ (نوع فعالیت):** فروشگاه، خدمات، عمده‌فروشی، فریلنسر، شخصی، حسابداری ساده، سایر
- **مرحله ۵ (خوش‌آمدگویی):** تایید نهایی مشخصات و شروع استفاده از فاکتور روبی

### ۲. صدور فاکتور چندپنجره‌ای (Invoice Creator & Multi-Window Tabs)
- سربرگ بنر آبی: **«برای افزودن سربرگ کلیک کنید»**
- کارت اطلاعات فاکتور: نام مشتری، شماره مشتری، شماره فاکتور، تاریخ شمسی
- جدول اقلام کالا/خدمات با محاسبه خودکار
- کارت تنظیمات: هزینه ارسال، تخفیف (درصدی/مبلغی)، بیعانه، بدهی قبلی
- دکمه‌های رادیویی نوع فاکتور (فروش/خرید/پیش‌فاکتور) و نوع پرداخت (نقدی/غیرنقدی)
- کارت افزودن شماره کارت بانکی و ثبت توضیحات
- دکمه **«ذخیره و اشتراک گذاری فاکتور»**
- **نوار چندپنجره‌ای پایین (Multi-Tab Bar):** دکمه `+` ایجاد فاکتور موقت، سربرگ فعال (پیش فاکتور ۱)، و دکمه `≡` نمایش مدال «پنجره‌های باز»

### ۳. مدیریت آیتم‌ها و کالاها (Items Management)
- عنوان صفحه **«آیتم‌ها»** همراه با دکمه **«+ ایجاد دسته‌بندی»** و فیلترها
- باکس حالت خالی با آیکن پوشه طلایی: «هنوز هیچ آیتمی اضافه نشده!»
- دکمه شناور ایجاد آیتم (`+`)
- مدال **«ایجاد آیتم»** شامل نام، واحد سنجش، قیمت و دکمه‌های انصراف / ایجاد

### ۴. طرح‌ها و پکیج‌های اشتراک (Pricing Plans)
- مدال **«از محدودیت‌ها عبور کنید!»**
- کارت **یک ساله (پیشنهادی)**: ۷۹۰ هزار تومان (با تخفیف ۲۰٪ نسبت به ۹۹۰ هزار تومان) - ماهانه ۶۵ هزار تومان
- کارت **شش ماهه**: ۶۹۰ هزار تومان - ماهانه ۱۱۵ هزار تومان
- کارت **یک ماهه (شروع)**: ۱۳۰ هزار تومان - پرفروش‌ترین
- دکمه **«فعالسازی یک ساله»** و لینک **«اشتراک داری؟ ورود به حساب کاربری»**

### ۵. نسخه طلایی و امکانات پیشرفته (Golden Subscription)
- بنر هدیه کانال تلگرام (یک روز اشتراک رایگان)
- **ویژگی‌های نسخه طلایی:**
  1. شخصی‌سازی فاکتورها (رنگ سربرگ، افزودن لوگو، مهر و امضا)
  2. افزودن نامحدود سطر در فاکتور
  3. دسترسی به اضافات فاکتور (ارسال، تخفیف، مالیات، بیعانه، بدهی قبلی)
  4. حذف لیبل تبلیغاتی در اشتراک‌گذاری
  5. خروجی PDF با کیفیت از فاکتورها

## 🚀 دستور ساخت و اجرا (Build & Run)

```bash
# اجرای پیش‌نمایش تعاملی وب
cd web_preview
npm install
npm run dev

# ساخت خروجی اپلیکیشن اندروید
./build_apk.sh
```
