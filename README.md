# حسابیار جاوید (Hesabyar Javid)

نرم‌افزار حسابداری آفلاین اندروید برای فروشگاه‌ها، کسب‌وکارهای خدماتی و شرکت‌های کوچک. رابط کاربری کاملاً فارسی و راست‌چین است و داده‌ها فقط روی دستگاه کاربر ذخیره می‌شوند.

## فناوری‌ها

- Kotlin، Jetpack Compose و Material Design 3
- MVVM + Repository Pattern + Clean Architecture
- Room / SQLite با تراکنش‌های اتمیک برای عملیات مالی
- Hilt، Navigation Compose، Coroutines و Flow
- تاریخ شمسی، رقم فارسی و ذخیره دقیق مبلغ به ریال (`Long`)

## قابلیت‌های نسخه ۱

- داشبورد فروش، خرید، سود، صندوق/بانک، بدهکاران و هشدار کمبود موجودی
- مدیریت کالا/خدمت، دسته‌بندی، واحد، قیمت، موجودی و حداقل موجودی
- مدیریت مشتری، فروشنده، مانده و گردش طرف حساب
- فاکتور فروش و خرید، مالیات، تخفیف، پرداخت نقدی و ابطالِ برگشت‌زننده
- دریافت، پرداخت، هزینه، درآمد، انتقال وجه، صندوق و بانک
- ثبت خودکار اسناد دوبل و ثبت سند دستی؛ تراز آزمایشی و دفتر اسناد
- گزارش سود و زیان و گزارش‌های ماه جاری
- Backup و Restore خام SQLite با Storage Access Framework؛ بدون مجوز حافظه گسترده
- ساختار مجوزدهی محلی برای نسخه Free / Professional که قابل جایگزینی با اعتبارسنجی سرور است

## اصول مهم مالی

- هر مبلغ در پایگاه داده **ریال** است؛ نمایش پیش‌فرض تومان است. این کار از خطای اعشاری جلوگیری می‌کند.
- عملیات فروش، خرید، دریافت، پرداخت، هزینه، درآمد، انتقال و ابطال هر کدام در یک تراکنش Room انجام می‌شوند؛ موجودی، مانده طرف حساب، مانده نقدی و سند حسابداری با هم ثبت می‌شوند.
- حذف کالا و شخص، حذف نرم (غیرفعال‌سازی) است. برای حفظ ردپای حسابداری، فاکتور نهایی و سند سیستمی ویرایش نمی‌شوند؛ ابطال، سند و گردش معکوس ثبت می‌کند.

## اجرا در Android Studio

1. Android Studio Ladybug یا جدیدتر و JDK 17 را نصب کنید.
2. پروژه را باز کنید و Android SDK Platform 35 را نصب کنید.
3. Sync Gradle را انجام دهید و `app` را اجرا کنید.

```bash
# پس از نصب Gradle 8.10+ (یا از پنل Gradle در Android Studio)
gradle testDebugUnitTest
gradle assembleRelease
```

خروجی بدون امضا در `app/build/outputs/apk/release/app-release-unsigned.apk` تولید می‌شود. برای انتشار، APK/AAB را با کلید اختصاصی و خارج از مخزن امضا کنید.

## انتشار در بازار و مایکت

- `applicationId`: `ir.javid.hesabyar`
- `versionCode` را با هر انتشار افزایش دهید.
- برای انتشار نهایی، `isMinifyEnabled` را پس از آزمایش فعال و قوانین ProGuard را تکمیل کنید.
- کلید امضا، فایل backup مشتری و هر اطلاعات حساس نباید وارد Git شوند.
- مجوز اینترنت در Manifest وجود ندارد؛ سیاست حریم خصوصی باید «داده‌ها فقط روی دستگاه» را تا زمان اضافه‌شدن سرویس ابری بازتاب دهد.

## نقشه توسعه بعدی

لایه‌های Repository و Local source of truth طوری تفکیک شده‌اند که منبع Remote برای همگام‌سازی، ورود شماره تلفن، چند دستگاه و Cloud Backup بدون تغییر UI جایگزین/افزوده شود.
