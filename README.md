# فاکتور فیدا (Factor Fida) - اپلیکیشن اندرویدی صدور فاکتور و مدیریت مالی

اپلیکیشن حرفه‌ای و سریع برای صدور فاکتور، مدیریت مشتریان، کالاها، بدهی‌ها و گزارش‌های سود و زیان؛ مناسب فروشگاه‌ها، کسب‌وکارهای کوچک، فریلنسرها و استفاده شخصی در ایران.

![Factor Fida Logo](web_preview/public/favicon.svg)

---

## 🌟 قابلیت‌ها و امکانات اپلیکیشن

### ۱. Onboarding چندمرحله‌ای (wizard)
- **مرحله ۱:** پرسش نام کاربر («سلام! من فیدا هستم. اسم شما چیه؟»)
- **مرحله ۲:** انتخاب کشور (ایران پیش‌فرض، ترکیه، آمریکا، کانادا، افغانستان، امارات، سایر)
- **مرحله ۳:** انتخاب استان و شهر با قابلیت جستجو
- **مرحله ۴:** نوع فعالیت (فروشگاه، خدمات، عمده‌فروشی، فریلنسر، شخصی، حسابداری ساده)
- **مرحله ۵:** صفحه خوش‌آمدگویی نهایی و ذخیره اطلاعات

### ۲. داشبورد اصلی (Dashboard)
- لوگو و آیکن فیدا + منوی Hamburger
- **کارت‌های آماری:** فروش امروز، دریافت امروز، بدهی مشتریان، تعداد فاکتورها
- **دکمه‌های اصلی سریع:** `+ فاکتور جدید` | `+ مشتری جدید` | `+ کالا جدید`
- **لیست آخرین فاکتورها:** شماره، مشتری، تاریخ شمسی، مبلغ و وضعیت

### ۳. صدور و ساخت فاکتور (Invoice Creator)
- انتخاب مشتری، شماره فاکتور، تاریخ شمسی
- جدول اقلام کالا/خدمات با محاسبه خودکار قیمت کل
- گزینه‌های هزینه ارسال، تخفیف درصدی یا مبلغی، بیعانه و بدهی قبلی
- **نوع فاکتور:** پیش‌فاکتور / فاکتور خرید / فاکتور فروش
- **نوع پرداخت:** نقدی / غیرنقدی
- ثبت شماره کارت بانکی جهت واریز
- خروجی چاپ و PDF، اشتراک‌گذاری از طریق Android Share Sheet

### ۴. مدیریت مشتریان (Customers)
- ثبت نام، شماره موبایل، تلفن، آدرس، توضیحات و مانده حساب
- جستجوی سریع، ویرایش، حذف، مشاهده فاکتورها
- ثبت پرداخت و کاهش بدهی
- تولید و ارسال متن یادآوری بدهی

### ۵. مدیریت کالا و خدمات (Products)
- ثبت نام، کد کالا، واحد، قیمت خرید، قیمت فروش، موجودی
- انتخاب سریع کالا هنگام صدور فاکتور

### ۶. مدیریت مالی و سود/زیان (Financials)
- ثبت درآمدها و هزینه‌ها
- گزارش‌های مالی (امروز، این هفته، این ماه، بازه دلخواه)
- گزارش سود و زیان دوره

### ۷. ۱۵ قابلیت هوشمند (Smart Features)
1. کپی سریع فاکتور قبلی
2. تبدیل پیش‌فاکتور به فاکتور فروش
3. ثبت پرداخت برای فاکتور بدهکار
4. تولید پیامک یادآوری بدهی
5. جستجوی سراسری سریع (Ctrl+K)
6. QR Code روی فاکتور
7. افزودن چند شماره کارت بانکی
8. انتخاب قالب فاکتور (مدرن، کلاسیک، ساده)
9. لوگوی اختصاصی فروشگاه
10. قفل برنامه با PIN
11. بکاپ و Restore محلی
12. Export/Import اطلاعات در قالب JSON
13. انتقال به گوشی جدید
14. پشتیبان‌گیری خودکار
15. بازگردانی حذف اشتباهی (Undo)

## 🚀 دستور ساخت و اجرا (Build & Run)

```bash
# اجرای پیش‌نمایش تعاملی وب
cd web_preview
npm install
npm run dev

# ساخت خروجی اپلیکیشن اندروید
./build_apk.sh
```
