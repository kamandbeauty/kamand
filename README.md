# طالع بین 🌙

اپلیکیشن اندرویدی طالع‌بینی شخصی — کاملاً آفلاین، فارسی و تقویم شمسی. **نسخهٔ اصلی ۱.۱۰.۱** (راهنمای انتشار: `RELEASE_AUDIT.md`).

## ویژگی‌ها

- **نقشهٔ تولد (پرمیوم)** — موتور نجومیِ آفلاین (خورشید/ماه با سری‌های میوس، سیاره‌ها با عناصر مداری JPL تا نپتون) + چرخِ فلکیِ نقاشی‌شده + سه‌گانهٔ بزرگ + گریدِ موقعیتِ سیاره‌ها + **ترانزیت‌های امروز** (آسمانِ حالا روی نقشهٔ تو) + ۱۳۴ متنِ تفسیری؛ طالعِ دقیق، خانه‌ها، زاویه‌ها و پس‌روی‌ها
- **طالع روزانه / هفتگی / ماهانه** — امتیاز عشق، کار، مالی، حال‌وهوا با برچسبِ شاعرانه + پیام روز + رنگ/عدد/ساعت شانس + خطِ آسمانِ امروز (خورشید و ماه در کدام برج) + «روزهای پیشِ رو» + نوارِ «آسمانِ امروزِ برج‌ها» (درصدِ امروزِ هر ۱۲ برج)
- **سازگاری عاطفی ۱۲×۱۲** — تحلیل رابطه با همهٔ برج‌ها + شریک عاطفی + تحلیل عمیقِ زوجین (پرمیوم)
- **طالع‌بینی در سنت‌های جهان** — چینی، ودیک، مایا، ایرانی (منازل قمر)، فراشماره، ابجد، یونانی، فالِ ازدواج، جم‌اوراکل، حیوانِ درون، فالِ تاروت — هرکدام با نشانِ تصویریِ اختصاصی
- **برج من** — شخصیت، نقاط قوت و ضعف، سبک عشق/کار/دوستی + نقشهٔ تولد
- **تمِ اصلیِ «شبِ مخملی»** — اثرِ هنریِ تولیدشدهٔ پس‌زمینه + قابِ تاروت + چرخِ فلکی؛ به‌همراه ۴ تمِ تیرهٔ دیگر و حالتِ روشن
- **پرمیوم** — اشتراک ماهانه/سالانه/مهمشی؛ فعال‌سازی با کدِ کمپین (پرداختِ درون‌برنامه‌ای همراه با انتشار در فروشگاه‌ها)
- **یادآوری روزانه** — اعلان ۸ صبح (قابل تنظیم، بدون مجوز اضافه)
- **حریم خصوصی کامل** — بدون سرور، بدون حساب کاربری، بدون مجوز موقعیت و اینترنت؛ همهٔ داده‌ها روی دستگاه + [نسخهٔ آنلاینِ سیاستِ حریمِ خصوصی](https://kamandbeauty.github.io/kamand/)

## معماری

```
lib/
├── core/       تاریخ شمسی، ارقام فارسی، تم Premium Mystical Glass
├── domain/     منطق خالص: موتور طالع قطعی، سازگاری، برج، اشتراک
├── data/       sqlite3 خام، ریپازیتوری‌ها، تنظیمات، اعلان، محتوای تولیدشده
├── providers/  Riverpod
├── widgets/    StarField، GlassCard، ...
└── screens/    آنبوردینگ ۷ مرحله‌ای + ۴ تب (خانه/برج من/عشق/پروفایل)
```

**موتور طالع قطعی است:** seed = `fnv1a32(برج + تاریخ شمسی)` — هیچ `Random` غیرقطعی وجود ندارد؛ هم‌برج‌ها در یک روز محتوای پایهٔ یکسان می‌بینند.

## توسعه

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release      # یا appbundle
```

محتوای طالع از `content/signs/*.json` تولید می‌شود:

```bash
python3 tool/build_content.py   # بازتولید lib/data/content/app_content.dart
```

## ساختار محتوا

- `content/` — استخرهای متن هر برج (۱۷۷۶ جمله) + متن‌های سازگاری
- `tool/` — تولیدکنندهٔ محتوا و آیکون
- `docs/` — سیاست حریم خصوصی و متن‌های صفحهٔ فروش

## انتشار

CI (`.github/workflows/android-build.yml`) روی هر push: بازتولیدِ محتوا (همگام‌سازیِ اجباری با سورس) → لینتِ متنِ فارسی → آنالیز → تست‌ها → APK و AAB امضاشده → GitHub Release. صفحهٔ حریمِ خصوصی هم با `.github/workflows/pages.yml` روی GitHub Pages منتشر می‌شود.
