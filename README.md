# علم اسامی

اپلیکیشن فارسی، راست‌به‌چپ و Offline-First برای دانشنامه نام‌ها، نام‌شناسی، ریشه‌شناسی، ابجد و تحلیل‌های سنتی.

> محاسبات ابجد و عددشناسی در این پروژه با برچسب «سنتی / تفسیری / سرگرمی» ارائه می‌شوند و ادعای علمی یا پیش‌بینی قطعی ندارند.

## وضعیت

این شاخه در حال ساخت نسخه پایه محصول است. داده‌های Seed اولیه برای تست رابط و موتور هستند و تا زمان تکمیل بررسی منابع، هر داده‌ای که منبع قطعی ندارد با وضعیت `unverified` نمایش داده می‌شود.

## اجرا

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## معماری

- Flutter / Dart
- Riverpod برای State و ViewModel
- SQLite محلی با Migration صریح
- Engineهای Pure Dart برای نرمال‌سازی، ابجد، عددشناسی و سازگاری
- Feature-first + Clean Architecture
- RTL و فارسی در نسخه اول
