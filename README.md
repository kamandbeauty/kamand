# شلم (Shelem) — بازی ورق ایرانی برای اندروید

یک اپلیکیشن اندرویدی کامل و آفلاین برای بازی **شلم**: شما به‌همراه یک یارِ
کامپیوتری در برابر دو حریف هوشمند. تمام قوانین رایج شلم پیاده‌سازی شده و
بیشترشان از صفحهٔ تنظیمات قابل تغییر است.

## امکانات

- **بازی کامل شلم**: پخش ۱۲ برگی + گلِ وسط، حراج (خواندن) از ۱۰۰ تا ۱۶۵،
  برداشتن گل و کنار گذاشتن ۴ برگ، اعلام حکم با اولین برگِ حاکم، ۱۲ دست بازی،
  امتیازدهی ۱۶۵ امتیازی.
- **چهار سطح سختی**: مبتدی، متوسط، حرفه‌ای، استاد (شمارش کارت، تشخیص خالِ
  تمام‌شده، همکاری با یار، جمع‌آوری امتیاز و بریدن هوشمند).
- **هفت زمین بازی**: قالی گل‌سرخ، قالی کاشان، قالی تبریز، گلیم سبز، میز چوبی
  قدیمی، پارکت و میز ماهوتی — به‌علاوهٔ پنج طرح پشتِ کارت.
- **قوانین اختیاری**: یاسا (خاموش / کمتر از حریف / کمتر از نصف قرارداد)،
  امتیاز حاکم (عددِ قرارداد یا امتیاز واقعی)، پاداش شلم (دوبرابر یا ۳۳۰)،
  خواندن شلم و سرشلم، اجبار صاحب‌دست در صورت پاسِ همه، امتیاز هدفِ بازی
  (۶۶۰ / ۱۱۰۰ / ۱۱۶۵ / ۱۲۰۰) و **حالت جوکر** (۲۰۰ امتیازی، گلِ ۶ برگی).
- **رابط کاربری فارسی و راست‌به‌چپ**، جدول امتیاز، مرور دست‌های گذشته،
  هایلایت کارت‌های مجاز، ذخیرهٔ خودکار بازی و ادامهٔ آن، صدا و لرزش.
- کاملاً **آفلاین** — بدون دسترسی اینترنت.

## ساختار کد

| مسیر | توضیح |
|---|---|
| `lib/model/` | مدل کارت و شمارش‌های رابط کاربری (سختی، سرعت، زمین، پشتِ کارت) |
| `lib/game/rules.dart` | کارت‌های مجاز، برندهٔ دست، امتیاز دست |
| `lib/game/scoring.dart` | امتیازدهی راند (یاسا، شلم، قراردادها) — کاملاً خالص |
| `lib/game/engine.dart` | موتور بازی: پخش، حراج، گل، حکم، بازی، امتیاز، ذخیره‌سازی |
| `lib/ai/bot.dart` | هوش مصنوعی: ارزیابی دست، خواندن، کنار گذاشتن گل، انتخاب کارت |
| `lib/state/` | تنظیمات کاربر و کنترلرِ بازی (حلقهٔ نوبت ربات‌ها، ذخیرهٔ خودکار) |
| `lib/ui/` | تم، ویجت‌های کارت و دیالوگ‌ها، صفحه‌های منو/میز/تنظیمات/قوانین |
| `test/` | تست قوانین، امتیازدهی، موتور، هوش مصنوعی و رابط کاربری |

## ساخت و اجرا

```bash
flutter pub get
flutter test
flutter build apk --release --split-per-abi
```

خروجی‌ها در `build/app/outputs/flutter-apk/` ساخته می‌شوند. همین کار در
GitHub Actions (`.github/workflows/android-build.yml`) هم انجام می‌شود و
فایل‌های APK/AAB به‌صورت artifact و در قالب یک Release منتشر می‌شوند.

## قانون‌های پیاده‌سازی‌شده (خلاصه)

۱۶۵ امتیاز هر راند = ۱۳ «دست» × ۵ (۱۲ دستِ بازی + برگ‌های کنارگذاشتهٔ حاکم)
به‌علاوهٔ ۴×۵ (پنج‌لوها) + ۴×۱۰ (ده‌لوها) + ۴×۱۰ (آس‌ها).
در حالت جوکر: ۲۰۰ امتیاز (جوکر قرمز ۲۰، جوکر سیاه ۱۵، گلِ ۶ برگی،
حداقل خواندن ۱۲۰ و حداکثر ۲۰۰).
