# طالع من 🌙

اپلیکیشن اندرویدی طالع‌بینی شخصی — کاملاً آفلاین، فارسی و تقویم شمسی.

## ویژگی‌ها

- **طالع روزانه / هفتگی / ماهانه** — امتیاز عشق، کار، مالی، حال‌وهوا + پیام روز + رنگ/عدد/ساعت شانس
- **سازگاری عاطفی ۱۲×۱۲** — تحلیل رابطه با همهٔ برج‌ها + شریک عاطفی
- **برج من** — شخصیت، نقاط قوت و ضعف، سبک عشق/کار/دوستی
- **یادآوری روزانه** — اعلان ۸ صبح (قابل تنظیم، بدون مجوز اضافه)
- **حالت تیرهٔ «آسمان شب»** + حالت روشن
- **حریم خصوصی کامل** — بدون سرور، بدون حساب کاربری، بدون مجوز موقعیت؛ همهٔ داده‌ها روی دستگاه

## معماری

```
lib/
├── core/       تاریخ شمسی، ارقام فارسی، تم Premium Mystical Glass
├── domain/     منطق خالص: موتور طالع قطعی، سازگاری، برج، اشتراک
├── data/       sqlite3 خام، ریپازیتوری‌ها، تنظیمات، اعلان، محتوای تولیدشده
├── providers/  Riverpod
├── widgets/    StarField، GlassCard، ...
└── screens/    آنبوردینگ ۷ مرحله‌ای + ۴ تب (خانه/برج من/عشق/پروفایل)
```

**موتور طالع قطعی است:** seed = `fnv1a32(برج + تاریخ شمسی)` — هیچ `Random` غیرقطعی وجود ندارد؛ هم‌برج‌ها در یک روز محتوای پایهٔ یکسان می‌بینند.

## توسعه

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release      # یا appbundle
```

محتوای طالع از `content/signs/*.json` تولید می‌شود:

```bash
python3 tool/build_content.py   # بازتولید lib/data/content/app_content.dart
```

## ساختار محتوا

- `content/` — استخرهای متن هر برج (۱۷۷۶ جمله) + متن‌های سازگاری
- `tool/` — تولیدکنندهٔ محتوا و آیکون
- `docs/` — سیاست حریم خصوصی و متن‌های صفحهٔ فروش

## انتشار

CI (`.github/workflows/android-build.yml`) روی هر push: آنالیز → ۸۱ تست → APK و AAB امضاشده → GitHub Release.
