# متن پیشنهادی صفحه مارکت فروشیار

## نام
فروشیار — دستیار آفلاین فروش

## توضیح کوتاه
مدیریت ساده مشتری، محصول، سفارش، فروش و سود؛ کاملاً آفلاین و فارسی.

## توضیحات کامل
فروشیار برای فروشندگان اینستاگرامی و کسب‌وکارهای کوچک ایرانی ساخته شده است. بدون ثبت‌نام و اینترنت، مشتری‌ها، محصولات و سفارش‌ها را مدیریت کنید و فروش و سود خود را ببینید.

### امکانات
- مدیریت مشتری‌ها و تاریخچه سفارش
- مدیریت محصولات، قیمت خرید و فروش و موجودی
- ثبت سفارش چندقلمی و محاسبه خودکار سود
- پیگیری وضعیت آماده‌سازی، ارسال و تحویل
- گزارش امروز و ماه جاری شمسی
- پیام آماده واتساپ برای مشتری
- نسخه پشتیبان JSON و بازیابی آفلاین
- رابط کاملاً فارسی، راست‌به‌چپ و ساده

### حریم خصوصی
فروشیار مجوز اینترنت ندارد و داده‌ها را از گوشی خارج نمی‌کند.

## دسته پیشنهادی
کسب‌وکار / مدیریت فروش

## موارد لازم پیش از انتشار
آیکن ۵۱۲×۵۱۲، حداقل سه اسکرین‌شات فارسی، ایمیل پشتیبانی، لینک سیاست حریم خصوصی و فایل AAB/APK امضاشده.
