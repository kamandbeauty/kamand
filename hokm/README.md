# حکم — بازی ورق ایرانی (نسخه‌ی وب)

پیاده‌سازی کامل بازی **حکم** به‌صورت چهارنفره و دو تیمی، با هوش مصنوعی برای هر سه بازیکن دیگر.
بازی کاملاً آفلاین است، روی موبایل و دسکتاپ کار می‌کند و وضعیت آن به‌صورت خودکار ذخیره می‌شود.

> الهام‌گرفته از بازی «پاسور حکم» (ir.doorbash.hokm) با تمرکز بر رعایت کامل و دقیق قوانین.

## اجرا

```bash
cd hokm
npm install
npm run dev      # http://localhost:4000
npm run build    # خروجی ایستا در dist/
npm test         # تست قوانین + تست رابط کاربری
```

## قوانینِ پیاده‌سازی‌شده

| قانون | توضیح | محل پیاده‌سازی |
| --- | --- | --- |
| تعیین حاکم | پخش یکی‌یکیِ ورق‌های رو؛ اولین آس حاکم می‌شود (نشان ♔) | `engine.js › hakemDealStep` |
| تعیین حکم | ۵ کارت اول به حاکم؛ او خال حکم را انتخاب می‌کند | `engine.js › startRound/chooseTrump` |
| پخش کارت | ۵ به حاکم، سپس ۵ به بقیه، سپس دو دور ۴تایی → ۱۳ کارت برای هر نفر | `engine.js › dealRest` |
| شروع دست اول | با حاکم | `engine.js › dealRest` |
| اجبار به خالِ زمین | اگر از خال زمین داری، باید همان را بازی کنی | `cards.js › legalCards` |
| برتری حکم | هر کارت حکم از همه‌ی کارت‌های خال‌های دیگر بالاتر است | `cards.js › trickWinnerIndex` |
| بریدن / رد دادن | نداشتن خال زمین ⇒ بریدن با حکم یا رد دادن | `cards.js` + هوش مصنوعی |
| چند برش | بالاترین حکم، دست را می‌بَرد | `cards.js › trickWinnerIndex` |
| شروع‌کننده‌ی دست بعد | برنده‌ی دست قبل | `engine.js › collectTrick` |
| برد راند | هر تیم که زودتر ۷ دست بگیرد | `engine.js › collectTrick/finishRound` |
| کت | ۷ بر ۰ ⇒ ۲ امتیاز | `engine.js › finishRound` |
| کتِ حاکم | کت کردن تیمِ حاکم توسط تیم مقابل ⇒ ۳ امتیاز | `engine.js › finishRound` |
| حاکمِ راند بعد | برد تیم حاکم ⇒ حفظ حاکمی؛ در غیر این صورت انتقال به نفر بعد | `engine.js › nextHakem` |
| پایان بازی | رسیدن به امتیاز هدف (۳/۵/۷/۱۱) یا اتمام تعداد راند (۵/۱۰/۱۵) | `engine.js › finishRound` |

ترتیب بازی خلاف عقربه‌های ساعت است: شما (پایین) ← حریف راست ← یار شما (بالا) ← حریف چپ.

## امکانات

- **هوش مصنوعی سه‌سطحی** (آسان/متوسط/سخت) با شمارش کارت، تشخیص خالِ تمام‌شده‌ی حریفان،
  همکاری با یار، بریدن و رد دادن هوشمند، کشیدن حکم و حفظ برگ‌های برنده.
- **زمین بازی قابل انتخاب:** قالی گل‌سرخ، قالی کاشان، قالی تبریز، گلیم سبز، میز چوبی قدیمی، پارکت.
- **۵ طرح پشت کارت**، سرعت بازی (آهسته/معمولی/سریع)، افکت‌های صوتی (Web Audio، بدون فایل).
- **ادامه‌ی بازی قبلی** (ذخیره‌ی خودکار در `localStorage`).
- **مشاهده‌ی دست‌های قبلی** با لمس کارت‌های جمع‌شده‌ی کنار زمین.
- **جدول امتیاز** راند‌به‌راند، نمایش حکم و تاج حاکم، شمارش دست‌ها.
- رابط کاربری کاملاً فارسی و راست‌به‌چپ، ریسپانسیو برای موبایل و دسکتاپ.

## ساختار

```
hokm/
├── src/game/cards.js    # کارت‌ها، قانون خال اجباری، تعیین برنده‌ی دست
├── src/game/engine.js   # ماشین حالت بازی و تمام قوانین/امتیازدهی
├── src/game/ai.js       # هوش مصنوعی (انتخاب حکم و انتخاب کارت)
├── src/game/sound.js    # افکت‌های صوتی با Web Audio API
├── src/components/      # کارت، صندلی بازیکنان، مودال‌ها
├── public/surfaces/     # تصاویر زمین بازی (قالی، میز، پارکت)
└── test/                # تست خودکار قوانین، قدرت هوش مصنوعی و رابط کاربری
```

## تست‌ها

- `npm run test:rules` — شبیه‌سازی ۴۰۰ بازی کامل و بررسی تک‌تک قوانین
  (اجبار خال، برتری حکم، ۷ دست، کت، کتِ حاکم، چرخش حاکمی، صحت مجموع امتیازها).
- `npm run test:ui` — اجرای واقعی رابط کاربری در jsdom: شروع بازی، تعیین حاکم،
  انتخاب حکم، بازی کردن کارت، جدول امتیاز، نمایش دست‌ها و تنظیمات.
- `npm run test:ai` — سنجش قدرت سطوح هوش مصنوعی در برابر یکدیگر
  (سخت در برابر آسان ≈ ۸۷٪ برد، در برابر متوسط ≈ ۶۵٪).
