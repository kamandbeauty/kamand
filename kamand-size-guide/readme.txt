جدول راهنمای سایز زیبا و واکنش‌گرا، دقیقاً زیر دکمهٔ خرید هر محصول ووکامرس. از استودیو جاوید.

== Description ==

این افزونه برای هر محصول یک جدول راهنمای سایز می‌سازد و آن را زیر دکمهٔ «افزودن به سبد خرید» نمایش می‌دهد. ساختهٔ استودیو جاوید.

= امکانات =

* جدول واکنش‌گرا با سرستون چسبان، ردیف‌های یکی‌درمیان و ستون اول چسبان هنگام پیمایش افقی
* چند راهنما برای یک محصول به‌صورت تب
* کلید تبدیل سانتی‌متر/اینچ (تبدیل واقعی اعداد، نه فقط تغییر برچسب)
* برجسته‌شدن خودکار ردیف سایز انتخاب‌شده در محصولات متغیر
* پنجرهٔ بزرگ‌نمایی، چاپ راهنما و نکتهای اندازه‌گیری همراه تصویر
* اختصاص راهنما به‌صورت اختصاصی، بر اساس دسته‌بندی یا پیش‌فرض فروشگاه
* شورت‌کد `[ksg_size_guide]` برای نمایش در هر جای محتوا
* رابط کاملاً فارسی و راست‌به‌چپ، بدون وابستگی به jQuery

== Installation ==

1. پوشهٔ `kamand-size-guide` را در `wp-content/plugins/` بگذارید.
2. افزونه را از پیشخوان فعال کنید.
3. از منوی «راهنمای سایز» یک راهنما بسازید و جدول آن را پر کنید.
4. در «ووکامرس › راهنمای سایز» راهنمای پیش‌فرض فروشگاه و ظاهر نمایش را تنظیم کنید.
5. در صفحهٔ ویرایش هر محصول می‌توانید راهنمای اختصاصی انتخاب کنید یا جدول اختصاصی بسازید.

== Frequently Asked Questions ==

= جدول کجا نمایش داده می‌شود؟ =

به‌صورت پیش‌فرض زیر دکمهٔ «افزودن به سبد خرید» (هوک `woocommerce_after_add_to_cart_form`). از تنظیمات می‌توانید آن را بالای تب‌های توضیحات یا زیر آن‌ها ببرید.

= چطور برای یک دسته‌بندی راهنمای پیش‌فرض بگذارم؟ =

در «محصولات › دسته‌ها» هنگام افزودن یا ویرایش دسته، فیلد «راهنمای سایز پیش‌فرض» را پر کنید.

= اعداد اینچ از کجا می‌آیند؟ =

ستون‌هایی که نوعشان «عدد اندازه‌گیری» باشد، هنگام تبدیل تقسیم یا ضرب در ۲.۵۴ می‌شوند؛ بقیهٔ سلول‌ها بدون تغییر می‌مانند.
